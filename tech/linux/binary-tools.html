Linux 二进制分析核心工具速查手册 ​

本文整理了 Linux 平台下 C/C++/D 语言开发、二进制分析、链接与库排查必备的 10 款工具，涵盖名称来历、核心描述、汇总表格、实用用途及常用命令，清晰区分各工具功能，解决命名晦涩、用途混淆的问题。

一、工具全称与核心描述 ​

逐一拆解每个工具的命名由来、核心定位，彻底搞懂每个工具的本质作用，告别死记硬背。

1. ar ​

  • 全称：Archive（档案 / 归档）
  • 核心描述：专门用于静态库（.a）打包、拆包与查看的工具，相当于静态库的 "压缩 / 解压缩工具"，将多个目标文件（.o）打包为 .a 静态库，也可拆解查看库内文件。
  • 本质：仅做文件打包，不参与代码编译与链接。

2. nm ​

  • 全称：Name List（符号名列表）
  • 核心描述：用于查看目标文件（.o）、静态库（.a）、可执行文件中的符号列表（函数名、全局变量名、外部依赖符号），快速判断指定函数 / 变量是否存在。
  • 本质：符号查看工具，排查未定义引用、符号冲突的核心工具。

3. objdump ​

  • 全称：Object Dump（目标文件信息转储）
  • 核心描述：二进制全能分析工具，可查看文件段结构、汇编代码、ELF 头部、函数分段信息，功能全面，是分析二进制底层结构的核心工具。
  • 本质：全功能二进制解析器，支持复杂结构查看与反汇编。

4. readelf ​

  • 全称：Read ELF（读取 ELF 文件）
  • 核心描述：专门针对 ELF 格式文件的解析工具，相比 objdump 更专注、输出更简洁，仅用于查看 ELF 文件的头部、段表、程序头、解释器等核心信息，无冗余内容。
  • 本质：ELF 格式专用查看器，专注 Linux/Unix 可执行文件分析。

5. ldd ​

  • 全称：List Dynamic Dependencies（列出动态依赖）
  • 核心描述：专门查看动态链接 ELF 文件的依赖库（.so），快速判断程序依赖的动态链接器、系统库，验证是否为真正的静态编译程序。
  • 本质：动态依赖排查工具，仅适用于动态链接文件。

6. file ​

  • 全称：File（文件类型识别）
  • 核心描述：通用文件类型识别工具，无需解析复杂结构，快速判断文件是 ELF 可执行文件、静态库、动态库、32/64 位、静态 / 动态链接、架构类型等。
  • 本质：文件类型快速鉴定工具，适用所有文件格式。

7. strip ​

  • 全称：Strip（剥离 / 去除）
  • 核心描述：二进制文件瘦身工具，剥离可执行文件、库文件中的调试信息、符号表、冗余数据，大幅减小文件体积，适用于程序发布场景。
  • 本质：二进制瘦身工具，不影响程序运行逻辑。

8. size ​

  • 全称：Size（大小）
  • 核心描述：查看目标文件、可执行文件中代码段（.text）、数据段（.data）、未初始化数据段（.bss）的占用大小，快速分析程序体积分布。
  • 本质：文件段体积统计工具，用于体积优化排查。

9. c++filt ​

  • 全称：C++ Filter（C++ 符号过滤器）
  • 核心描述：用于将 C++ 编译器修饰的符号名还原成原始的函数签名，解决 C++ 名称修饰导致的符号可读性问题，方便调试和分析。
  • 本质：符号还原工具，将修饰符号转换为可读的函数原型。

10. ddemangle ​

  • 全称：D Demangle（D 语言符号解修饰）
  • 核心描述：专门用于将 D 语言编译器修饰的符号名还原成原始的函数定义签名，支持 D 语言特有的名称修饰规则，是 D 语言开发调试的必备工具。
  • 本质：D 语言符号还原工具，将修饰符号转换为 D 语言可读的函数定义。

三、各工具实用用途与常用命令 ​

1. ar（静态库操作） ​

bash
# 查看静态库内包含的目标文件
ar t libxxx.a

# 拆解静态库，提取内部目标文件
ar x libxxx.a

# 将多个 .o 文件打包为静态库
ar rcs libnew.a a.o b.o

2. nm（符号查看） ​

bash
# 查看可执行文件 / 库的所有符号
nm xxx

# 筛选指定函数是否存在
nm xxx | grep 函数名

# 仅查看已定义的函数符号
nm xxx | grep ' T '

3. objdump（二进制全解析） ​

bash
# 查看文件段结构，判断是否开启函数分段
objdump -h xxx.o

# 查看文件完整头部信息
objdump -x xxx

# 反汇编代码段，查看汇编指令
objdump -d xxx

4. readelf（ELF 专用解析） ​

bash
# 查看 ELF 程序的动态链接器（解释器）
readelf -l 可执行文件 | grep interpreter

# 查看 ELF 文件完整头部信息
readelf -h 可执行文件

# 查看程序段与节区信息
readelf -S 可执行文件

5. ldd（动态依赖排查） ​

bash
# 查看程序所有动态库依赖
ldd 可执行文件

# 验证是否为真静态程序：静态文件执行后会提示 not a dynamic executable

6. file（文件类型识别） ​

bash
# 快速判断文件类型、架构、链接方式
file 可执行文件/库文件

7. strip（二进制瘦身） ​

bash
# 基础瘦身，剥离调试信息
strip 可执行文件

# 仅剥离调试符号
strip -g 可执行文件

8. size（段大小统计） ​

bash
# 查看文件各段占用大小
size 可执行文件/xxx.o

# 以易读格式显示
size -h 可执行文件

9. c++filt（符号还原） ​

bash
# 还原单个修饰符号
c++filt _Z3fooi

# 从 nm 输出中还原所有符号
nm 可执行文件 | c++filt

# 还原并显示函数参数类型
c++filt -n _ZN3std9basic_iosIcSt11char_traitsIcEE7eofEv

10. ddemangle（D 语言符号还原） ​

bash
# 还原单个 D 语言修饰符号
ddemangle _D3foo3barFZv

# 从 nm 输出中还原所有 D 语言符号
nm d_program | ddemangle

# 还原并显示完整的 D 语言函数定义
ddemangle _D4core4test3fooFiiZv

四、工具使用场景速配（结合 D 语言 /musl 静态编译） ​

  • 验证程序是否真静态：ldd + file
  • 检查第三方静态库能否裁剪函数：objdump -h
  • 查看静态库内部文件：ar t
  • 排查函数是否被编译进程序：nm
  • 查看 ELF 解释器：readelf
  • 发布前缩小程序体积：strip
  • 还原 C++ 修饰符号为可读函数名：c++filt
  • 还原 D 语言修饰符号为可读函数定义：ddemangle
